Sossoldi 32-bit
🍴 This is an unofficial fork of RIP-Comm/sossoldi, with the specific goal of getting the app to build and run on old 32-bit (armeabi-v7a) Android devices, such as tablets running Android 7.x (API 24) that modern versions of Flutter/Android Gradle Plugin no longer support out of the box.
All credit for the project and the original code goes to the RIP-Comm team. This fork is not affiliated with or endorsed by them: it is maintained for personal use by @daddie2 and shared in case it helps others with the same problem (old 32-bit Android tablets).
